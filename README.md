## ✨ Features

- 🎨 **Dark minimal design** with a teal accent, plus an automatic light mode that follows your system theme
- 📱 **Fully responsive**, from phones to wide desktop screens
- 🧭 **Sticky navbar** with smooth scrolling between sections
- 🃏 **Project cards** with hover animations, built with CSS Grid
- 🕒 **Experience timeline** for roles and education
- 🎬 **Subtle entrance animation** using CSS `@keyframes`
- 🎛️ **Easy theming**: change a few CSS variables to restyle the whole site
- ⚡ **Zero dependencies**, so it loads instantly

## 🚀 Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/Harshvardhan2612/Portfolio.git

# 2. Go into the folder
cd Portfolio

# 3. Open index.html in your browser
```

That's it. There's nothing to install or build.

## 🎨 Customize

All colors live in one place at the top of `style.css`:

```css
:root {
  --bg: #0b0f14;
  --surface: #121923;
  --text: #e6edf3;
  --accent: #2dd4bf; /* change this to restyle the whole site */
}
```
