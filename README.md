## Overview

This project presents my background, technical skills, projects, and experience in one fast-loading page. It was designed and built from scratch to practise core front-end fundamentals: semantic markup, responsive layout, and maintainable CSS.

## Features

- **Responsive layout** that adapts from mobile to desktop using Flexbox, CSS Grid, and media queries
- **Automatic light and dark themes** that follow the visitor's system preference
- **Centralised theming** through CSS custom properties, so a design change is a single edit
- **Sticky navigation** with smooth scrolling between sections
- **Interactive project cards** with hover transitions
- **Experience timeline** for roles and education
- **No dependencies**, so there is no build step and the page loads quickly

## Getting Started

No installation or build step is required.

1. Clone the repository:
   ```bash
   git clone https://github.com/Harshvardhan2612/Portfolio.git
   ```
2. Open the project folder.
3. Open `index.html` in any modern web browser.

## Customisation

Theme colours are defined once at the top of `style.css`:

```css
:root {
  --bg: #0b0f14;
  --surface: #121923;
  --text: #e6edf3;
  --accent: #2dd4bf;
}
```

Changing these values updates the entire site.
